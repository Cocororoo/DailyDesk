# 失败处理

先打开本轮报告，按失败项目处理。保留原始记录，只补跑未完成的游戏或原生任务。

| 游戏与现象 | 处理方式 |
| --- | --- |
| 原神未能打开队伍配置，秘境没有开始 | 检查 BetterGI 当前界面和本轮日志，确认一条龙已加载正确队伍后，只启动原神。重复出现时先修正队伍预设，不连续重跑三游戏任务。 |
| 原神提示圣遗物背包空间不足，奖励无法结算 | 停止秘境任务，在游戏中整理背包，再单独补跑原神秘境。该次秘境未结算时不要把它计为已消耗树脂或已领取奖励。 |
| 星铁实训达到 500，但缺少领奖记录 | 保留为未完成，使用三月七小助手原生界面单独补做实训领奖。不要为补领奖重复清体力。 |
| 终末地停在标题画面，`__ScenePrivateLoginContinue` 连续识别超时 | 在游戏中完成标题页继续操作并进入大世界，再单独启动终末地。整轮未启动的其他游戏无需重跑。 |
| 用户关闭监督窗口，记录状态为已中止 | 按报告确认最后完成的游戏和原生任务，只恢复剩余项目。用户主动中止不归为自动化故障。 |
| 配置校验失败或运行时发现原生配置已变化 | 按报告指出的游戏检查原生助手配置，修正后重新预检。不要用历史报告或旧配置覆盖当前原生设置。 |

任务状态与收益证据分开判定。原生任务成功表示流程正常结束，领奖、资源变化和副本结算仍需对应日志或游戏画面支持。
